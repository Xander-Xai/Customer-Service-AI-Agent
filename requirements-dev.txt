# Dev dependencies for CI/CD — LANE B: supported development compatibility.
#
# This is NOT the canonical coverage toolchain. The canonical, fully pinned
# coverage lane (LANE A) lives in .github/workflows/ci.yml ("Install
# dependencies": pytest==7.4.4 / pytest-asyncio==0.21.1 / pytest-cov==5.0.0 /
# coverage==7.4.4) and exists to keep the committed coverage number
# reproducible. This file instead tracks the supported development/CI
# compatibility surface (pytest 8 era).
#
# pytest-asyncio floor 0.23.4: pytest>=8 removed `FixtureDef.unittest`. While
# pytest-asyncio *0.23.0–0.23.3* still access that attribute during async
# fixture setup, 0.23.4 is the first 0.23.x release that restores pytest 8
# compatibility. The floor must therefore be >=0.23.4 — a `>=0.23.0` range
# would still permit the same 3 setup errors in
# tests/integration/test_integration.py. A regression test
# (tests/unit/test_repository_contract.py) pins this floor.
pytest>=8.0.0,<9.0.0
pytest-asyncio>=0.23.4,<0.24.0
pytest-cov>=4.1.0
# Hard per-test wall-clock cap for the distributed runtime acceptance tests.
# Those tests spawn real OS processes (Celery prefork workers) and wait on
# broker visibility timeouts; without a cap a hung worker would stall CI until
# the job-level timeout. The `timeout` marker is a no-op when the plugin is
# absent, so this only takes effect where it is installed (dev + CI runtime
# lane). Never enable the plugin globally in the canonical coverage lane — it
# would change timings the committed coverage figure was measured under.
pytest-timeout>=2.3.0
mypy>=1.8.0

# Linter / formatter. This is the **canonical** Ruff pin for the repository and
# must stay byte-equal to the `.pre-commit-config.yaml` `rev:` (issue #71).
#
# Before this line, Ruff appeared in no requirements file, so `make lint` ran
# whatever `ruff` happened to be on PATH while the pre-commit hook ran 0.4.0 --
# two different rule sets under the same `make lint`. The version is a hard pin
# rather than a range on purpose: Ruff's formatter output changes between
# releases, and a range would make `make format` non-reproducible for anyone who
# installs on a different day.
#
# tests/unit/test_repository_contract.py asserts the two declarations agree, so
# this pin cannot silently drift away from the pre-commit hook again.
ruff==0.4.0
